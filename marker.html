Marker Hiro

Tampilkan atau cetak marker di bawah ini, lalu arahkan kamera smartphone yang membuka halaman Demo AR. Marker harus terbaca utuh (tidak terlipat, pencahayaan cukup).

Buka Demo AR

Cara Pakai

  1. Tampilkan / cetak marker Biarkan cukup besar di layar (idealnya selebar telapak tangan).
  2. Buka halaman Demo AR Di ar.html, izinkan akses kamera saat diminta browser.
  3. Arahkan kamera ke marker Status berubah menjadi “Marker terdeteksi” dan robot 3D muncul di atas marker.

Troubleshooting

  • Pastikan halaman dibuka via HTTPS (github.io) — kamera ditolak di konteks HTTP.
  • Jika marker tidak terdeteksi: tambah cahaya, jaga marker rata, mundurkan sedikit kamera.
  • Marker tercetak idealnya hitam pekat di atas kertas putih; hindari pantulan lampu.
