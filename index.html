Augmented Reality Berbasis Marker di Web

Implementasi augmented reality dengan mekanisme marker-based: kamera smartphone mendeteksi marker fidusia (pola kotak hitam–putih), lalu model 3D animasi dirender tepat di atas marker — berjalan sepenuhnya di browser, tanpa instalasi aplikasi, dan di-deploy pada situs github.io.

▶ Buka Demo AR Cetak / Tampilkan Marker

Apa itu Marker-Based AR?

Marker-based AR adalah teknik augmented reality yang membutuhkan penanda fisik (marker) berbentuk pola yang sudah diketahui komputer. Komputer membandingkan citra dari kamera dengan pola marker; ketika cocok, posisi dan orientasi marker dihitung (pose estimation) sehingga konten 3D dapat ditempatkan secara konsisten pada penanda tersebut.

  1. Akuisisi citra Browser membuka kamera smartphone melalui API getUserMedia (wajib HTTPS).
  2. Deteksi marker Setiap frame dianalisis dengan jsartoolkit5 untuk menemukan pola fidusia (marker Hiro).
  3. Estimasi pose Koordinat sudut marker dipakai menghitung rotasi & translasi kamera terhadap marker.
  4. Rendering 3D Model glTF dianimasikan dengan THREE.AnimationMixer dan digambar seolah menempel pada marker.

Spesifikasi Teknis

library

AR.js 3.4.8

Marker tracking berbasis jsartoolkit5, di-pin via CDN jsDelivr.

framework 3D

A-Frame 1.6.0

Framework scene grafis berbasis HTML (wrapper three.js) untuk deklaratif 3D.

konten

Model glTF animasi

RobotExpressive.glb dengan 9 klip animasi yang bisa dipilih.

marker

Preset Hiro

Marker fidusia standar AR.js + smoothing agar tracking lebih stabil.

animasi

THREE.AnimationMixer

Mixer ditulis manual (bawaan A-Frame tidak punya komponen animation-mixer).

hosting

GitHub Pages

Di-deploy pada situs github.io — gratis & HTTPS otomatis.

Catatan Penting

  • Kamera hanya bisa diakses lewat konteks aman: HTTPS (github.io) atau localhost.
  • Gunakan browser modern (Chrome/Edge/Safari) yang mendukung WebGL + WebRTC.
  • Jika memakai komputer, buka ar.html lalu tampilkan marker ini di layar kedua / HP.
  • Tracking marker bekerja paling baik dengan pencahayaan cukup dan marker tidak terlipat.
